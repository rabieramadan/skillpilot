Supported File Types for AI Analysis

Documents

  • PDF (.pdf)
  • Word (.doc, .docx)
  • PowerPoint (.ppt, .pptx)
  • Text (.txt)
  • RTF (.rtf)
  • OpenDocument (.odt)

Images

  • JPEG (.jpg, .jpeg)
  • PNG (.png)
  • GIF (.gif)
  • BMP (.bmp)
  • WebP (.webp)
  • SVG (.svg)
  • TIFF (.tiff, .tif)

Spreadsheets

  • Excel (.xls, .xlsx)
  • CSV (.csv)
  • OpenDocument (.ods)

Code Files

  • Python (.py)
  • JavaScript (.js, .ts)
  • Java (.java)
  • C/C++ (.c, .cpp, .h)
  • HTML/CSS (.html, .css)
  • And 20+ more languages

Data Files

  • JSON (.json)
  • XML (.xml)
  • YAML (.yaml, .yml)

Archives

  • ZIP (.zip)
  • TAR (.tar)
  • GZIP (.gz)
